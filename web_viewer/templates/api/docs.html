REST API endpoints for CyberSecurity Suite

Authentication

All API endpoints require authentication. Use session authentication or token authentication.

Available Endpoints
Endpoint Methods Description
/api/targets/ GET, POST List and create targets
/api/targets/{id}/ GET, PUT, DELETE Retrieve, update, delete target
/api/scans/ GET, POST List and create scans
/api/vulnerabilities/ GET, POST List and create vulnerabilities
/api/reports/ GET, POST List and create reports
/api/stats/ GET Get overall statistics
Example Usage
curl -H "Authorization: Token YOUR_TOKEN" http://localhost:8000/api/targets/
